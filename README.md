# Capital Conecta+ — GitHub Pages sem pasta CSS/JS

Nesta edição, TODO o CSS e JavaScript necessário de cada página está embutido
diretamente dentro de cada arquivo HTML.

Assim, no GitHub você só precisa subir:
- os arquivos .html
- a pasta assets
- .nojekyll (se visível)
- README.md é opcional

Não existe pasta css nem pasta js nesta versão.
